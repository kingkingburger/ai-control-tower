DAY 1

왜 Claude Code인가

💻

Claude Code = 컴퓨터 제어 OS

브라우저 기반 AI(ChatGPT, Claude Web)와 달리, 로컬 컴퓨터의 모든 파일을 직접 읽고 쓰며 제어한다. SaaS 시대의 워크플로우가 자연어 레이어까지 내려온 것.

🔓

"기술 해방"

코딩이 전문 영역으로 존재하던 시대가 끝나고, 자연어로 컴퓨터를 조작할 수 있게 되면서 각자의 도메인 전문성이 곧 무기가 되는 시대.

📈

지식 노동의 재정의

  • 농경사회: 경험 · 연장자 우위
  • 제조업: 분업 · 실행력
  • 지식 노동: IQ · 자율성
  • AI 시대: 맥락 공급 · 판단 기준 · 결과 검증
🏆

해커톤 RALPH 사례

12시간 AI만 코딩 해커톤. 1등 팀: 10만 줄 코드. 손을 안 댄 팀이 1·2등 — 스펙 설계 4시간 + AI 무한 루프 구현 전략이 핵심.

DAY 1

핵심 기능 7가지

🧠

CLAUDE.md

매 세션마다 시스템 프롬프트 아래 자동 로딩. 짧고 정확하게 — 잘못된 정보가 들어가면 토큰 낭비와 오작동.

🗒

Auto Memory

대화 내용을 자동으로 프로젝트별 memory.md에 저장. 앞 200줄 우선 로딩, 필요시 에이전틱 추가 로딩.

⚡

Skills

Progressive Disclosure — CLAUDE.md와 달리 필요할 때만 로드. 컨텍스트 효율의 핵심 설계 원칙.

👥

Sub-agents & Teams

빈 컨텍스트에서 병렬 실행. 읽기 분리에 최적, 쓰기 병렬은 충돌 위험. 팀즈는 팀메이트 간 소통 가능.

"토큰을 더 많이 효과적으로 쓸 수 있는 구조를 이해하는 것이 AI 레버리지의 핵심이다."

— 정구봉

DAY 2

MCP vs 스킬 & Context Sync

🔌

MCP = 표준화 레이어

  • USB-C / HTTP처럼 이해 — AI가 SaaS 데이터를 표준 방식으로 접근
  • Anthropic이 제작, Linux Foundation으로 이전 중
  • Tool / Resource / Prompt 중 Tool만 주로 사용
  • toolSearch: true 설정으로 미사용 MCP 토큰 절약
🛠

스킬 = 커스터마이징 레이어

  • Python/API 스크립트를 Claude Code가 직접 실행
  • 에러 시 자기개선 루프 가능 (MCP는 불가)
  • 커스텀 에러 핸들링, 포맷 변환 자유로움
  • "MCP는 Chrome DevTools만 남기고 나머지는 스킬로"

Clarify — Planning 이전의 의도 추출

🎯 암묵지 → 명시지

맥킨지 보고서: 전문가가 코드 작업 중 60%를 '이해'에 소비. 잘 안다고 잘 전달되는 것이 아니며, 한국 고맥락 문화는 AI 활용 시 오히려 비용이 된다.

Garbage In, Garbage Out Unknown Unknowns

🔍 Clarify 4단계 프로토콜

  • 1. Capture — 현재 요청 포착
  • 2. AskUserQuestion — 가설 기반 다지선다 설계
  • 3. Select Options — 사용자 선택
  • 4. Before/After — 결과 비교

Clarify에 Opus(고성능) 모델, 구현에 소형 모델 — 토큰은 투자

  • Playwright MCP: 봇 탐지 우회 (네이버 등)
  • Chrome DevTools: 개발 테스트 용도

💻 비개발자를 위한 Git

  • commit = 되돌릴 수 있는 저장점
  • branch = 사본에서 작업
  • PR = 검토 요청

DAY 4

멀티 에이전트 세션 랩 & 스킬 제작

🤖 세션 랩 — "작업 후 책상 정리 루틴"

작업 세션 종료 후 자동으로 4개 에이전트를 병렬 실행:

  • Document Updater — 문서 업데이트 제안
  • Automation Scout — 새 스킬/자동화 제안
  • Learning Miner — 배울 점 추출
  • Sustainability Tester — 지속 가능성 검증

Phase: 변경 확인 → 병렬 분석 → 중복 검사 → 액션 선택

📚 스킬 제작 베스트 프랙티스

Anthropic 공식 가이드:

  • 1. Claude와 대화하며 실제 작업 수행
  • 2. "방금 했던 작업을 스킬로 만들어줘"
  • 3. 새 세션에서 스킬 실행
  • 4. 의도와 다른 부분 → 원래 세션에서 수정
  • 5. 반복하여 다듬기

"완벽한 스킬은 만들 수 없다. 만들고 실행하고 검증하면서 컴파운드 해야 한다."

Key Takeaways

  • 01 Claude Code는 코딩 도구가 아니라 컴퓨터를 자연어로 제어하는 OS다
  • 02 똑똑한 AI를 쓰는 것보다 AI에게 올바른 맥락을 공급하는 시스템을 만드는 것이 핵심

  • 05 Build → Use → Notice → Debug → Fix → Document 사이클을 반복하며 복리를 쌓아라
