# [AI Native Camp 2기] Day 1 — AI 네이티브 마인드셋과 Claude Code 완전 정복

## 요약

AI Native Camp 2기 Day 1 세션(2026.03.02, 온라인)으로 총 4시간 분량의 강의다. 김성중이 캠프 오프닝과 운영 안내를 진행하고, 장원준이 AI 시대의 지식 노동 변화와 Claude Code를 OS로 활용해야 하는 이유를 설파하며, 정구봉이 Claude Code 설치부터 메모리(CLAUDE.md/Auto Memory), 스킬(Skills), 서브 에이전트, 에이전트 팀즈까지 핵심 기능 7가지를 실습한다. 핵심 메시지는 **'AI 네이티브 업무란 Claude Code를 OS로서 활용하여 컴퓨터 전체를 자연어로 제어하는 것'**이며, 도구 자체가 아니라 **프레임워크와 마인드셋**을 체득하는 것이 본질이라는 것이다.

**주요 포인트 3개:**
1. Claude Code는 단순 코딩 도구가 아니라 '컴퓨터를 제어하는 OS'로 인식해야 하며, 모든 파일·앱·서비스를 자연어로 통제할 수 있는 시대가 왔다
2. '기술 해방' — AI로 인해 비개발자도 기술자의 영역을 수행할 수 있게 되었고, 도구 위의 마인드셋(프레임워크)이 가장 중요하다
3. 토큰을 더 많이 효과적으로 쓸 수 있는 구조(서브 에이전트, 에이전트 팀즈)를 이해하는 것이 AI 레버리지의 핵심이다

## 인사이트

### 핵심 아이디어

- **Claude Code = 컴퓨터 제어 OS** — 브라우저 기반 AI(ChatGPT, Claude Web)와 달리, Claude Code는 로컬 컴퓨터의 모든 파일을 직접 읽고 쓰며 제어한다. SaaS 시대의 워크플로우가 자연어 레이어까지 내려온 것
- **"기술 해방"** — 소프트웨어·코딩이 전문 영역으로 존재하던 시대가 끝나고, 자연어로 컴퓨터를 조작할 수 있게 되면서 각자의 도메인 전문성이 곧 무기가 되는 시대
- **지식 노동의 재정의** — 농경사회(경험·연장자 우위) → 제조업(분업·실행력) → 지식 노동(IQ·자율성) → AI 시대(맥락 공급·판단 기준 설정·결과 검증)로 핵심 역량이 전환
- **토큰을 많이 쓸 수 있는 능력 = AI 레버리지 실력** — 서브 에이전트, 에이전트 팀즈 등으로 병렬 처리하면 메인 컨텍스트를 오염시키지 않고 더 많은 일을 위임할 수 있다
- **스킬의 Progressive Disclosure** — CLAUDE.md는 매 세션마다 전부 로딩되지만, 스킬은 필요할 때만 점진적으로 로드된다. 컨텍스트 효율의 핵심 설계 원칙

### 적용 가능한 점

- **User Memory에 이름·선호 도구·선호 패턴 설정**: 매 세션 자동 반영되어 일관된 경험 제공
- **Output Style을 Explanatory로 설정**: 학습 단계에서 Claude가 '왜 이렇게 했는지'까지 설명해주어 이해도 향상
- **Verbose Output 활성화**: thinking 과정과 tool 사용 내역까지 볼 수 있어 Claude의 사고 과정 파악 가능
- **서브 에이전트는 '읽기' 작업 분리에 최적**: 병렬로 여러 소스를 읽어오되, 동시에 다른 파일에 쓰기하는 서브 에이전트 패턴은 비추천
- **에이전트 팀즈로 다관점 검토**: 개발자/비개발자/데빌스 애드보킷 등 페르소나를 부여하여 다각도 리뷰 후 메인 에이전트가 최종 산출물 생성
- **CLAUDE.md는 짧고 정확하게**: 잘못된 정보(없는 폴더 경로 등)가 들어가면 토큰 낭비와 오작동 유발
- **해커톤 RALPH 패턴**: 스펙을 4시간 동안 정밀하게 설계 → AI가 12시간 무한 루프로 구현. 인간이 손 안 댄 팀이 1·2등

- **도구의 진화**: 기계어 → 어셈블리 → 프로그래밍 → API/SaaS → 자연어
- **Claude Code = 컴퓨터 제어**: 로컬 파일 읽기/쓰기, MCP로 Notion·Slack·Gmail 등 연결, PPT·리포트 자동 생성

### 4. Part 2 — Claude Code 환경 세팅 실습 [01:34:00 - 02:24:00]
**발표자: 정구봉, 보조: 장원준(실시간 통역)**

Claude Code 설치, 로그인, 기본 설정.

- **설치**: `npm install -g @anthropic-ai/claude-code` (Mac), 윈도우는 Git Bash 설치 후 진행
- **CLI vs GUI**: CLI(터미널)에서 써야 Claude Code의 모든 능력 활용 가능. 코워크(웹)는 기능 제한
- **설정 추천**: 출력 스타일(Output Style) → Explanatory, 언어(Language) → Korean, 자동 업데이트 채널(Auto Update Channel) → Latest, 상세 출력(Verbose Output) → True
- **에디터**: VS Code / Cursor / AntiGravity 중 선택. AI 기능은 쓰지 않고 파일 뷰어로만 활용 추천
- **Rewind 기능**: 잘못 쌓은 컨텍스트를 되돌리는 기능

### 5. 핵심 기능 7가지 — 메모리, 스킬, 서브에이전트, 팀즈 [02:31:00 - 03:57:00]
**발표자: 정구봉, 보조: 장원준**

Claude Code의 핵심 기능을 하나씩 실습.

#### 5-1. 메모리 (CLAUDE.md + Auto Memory) [02:32:00 - 02:58:00]
- **CLAUDE.md**: 매 세션마다 시스템 프롬프트 바로 밑에 자동 로딩. 짧을수록 좋음
- **User Memory**: 모든 폴더에서 공통 적용 (이름, 선호 도구, 선호 패턴)
- **Auto Memory**: 최근 추가된 실험적 기능. 대화 내용을 자동으로 프로젝트별 memory.md에 저장. 앞 200줄 우선 로딩, 필요시 에이전틱하게 추가 로딩
- **init 명령어**: 폴더 구조를 분석하여 CLAUDE.md 자동 생성

#### 5-2. 스킬 (Skills) [03:09:00 - 03:19:00]
- **Progressive Disclosure**: CLAUDE.md와 달리 필요할 때만 점진적으로 로드
- SKILL.md + 하위 파일들로 구성. 프론트매터(name, description)가 필수
- 유니버셜: Claude Code, Codex, GitHub, Claude Desktop 등에서 모두 사용 가능
- 슬래시 명령으로 직접 호출하거나, 상황에 맞게 자동 발동

#### 5-3. 서브 에이전트 (Sub-agents) [03:23:30 - 03:42:00]
- **핵심 원리**: 빈 컨텍스트에서 별도 프로세스로 실행 → 메인 세션 컨텍스트 비오염
- 병렬 실행 가능 ("익스플로어 에이전트 세 개 돌려서 분석해")
- 모델 지정 가능 (Opus/Sonnet/Haiku)
- **주의**: 서로 다른 쓰기(Write) 작업을 병렬 서브 에이전트에 맡기면 충돌. 읽기(Read) 분리에 최적
- 서브 에이전트 아래 서브 에이전트(재귀 호출)는 Anthropic이 차단

#### 5-4. 에이전트 팀즈 (Agent Teams) [03:44:00 - 03:56:00]
- **서브 에이전트와의 차이**: 팀메이트 간 커뮤니케이션 가능, 유저가 개별 팀메이트에게 직접 명령 가능
- 아직 Preview 기능 — settings.json에서 활성화 필요
- Task 목록 생성 → 팀메이트 배정 → 병렬 실행 → 메인 에이전트와 소통
- 시퀀셜하게 설계하고 스킬로 저장하는 것이 베스트 프랙티스

### 6. 마무리 및 과제 안내 [03:56:00 - 03:59:30]
**진행자: 김성중, 정구봉**

내일(Day 2) 예고: MCP 딥다이브, 업무 도구 연결. 플러그인·훅은 이후 세션에서 스킬 제작 과정 중 자연스럽게 다룰 예정.
