# 문서 언어 정책

## 기본값

하네스가 새로 작성하거나 갱신하는 문서는 기본적으로 한국어로 작성한다.

예외:

- 코드, 명령어, 파일 경로, 환경 변수, API 이름은 원문을 유지한다.
- 기존 문서가 영어로 작성되어 있고 일관성이 더 중요한 경우에는 기존 문체를
  따른다.
- 외부 공개용 문서나 사용자가 영어를 명시한 문서는 영어로 작성한다.

## 작성 기준

- 한국어 설명은 짧고 실행 가능하게 쓴다.
- 추상적인 선언보다 에이전트가 따를 수 있는 규칙과 절차를 우선한다.
- 프로젝트 팀 메모리, 세션 종료 기록, 증강 후보는 한국어로 누적한다.
- 대상 프로젝트 문서에 승격할 때도 해당 프로젝트의 언어 규칙을 먼저 확인한다.
