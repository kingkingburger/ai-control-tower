# Git 정책

## 기본값

- git 명령은 대상 저장소 루트에서 실행한다.
- 편집 전과 커밋 전에는 `git status --short`를 확인한다.
- 사용자의 무관한 변경을 되돌리거나 덮어쓰거나 stage하지 않는다.
- 사용자가 명시적으로 요청하지 않으면 push하지 않는다.
- 커밋은 작고 한 가지 목적에 맞춘다.

## 커밋 메시지

대상 저장소의 커밋 언어와 형식을 따른다. 대상 저장소에 규칙이 없으면 기본값은
한국어와 다음 형식이다.

```text
{type}: {설명}
```

기본 허용 타입:

- `feat`
- `fix`
- `docs`
- `refactor`
- `test`
- `chore`

## Dirty Worktree

무관한 변경이 이미 있으면 다음 순서로 처리한다.

1. 상태 요약에서 해당 변경을 식별한다.
2. 그대로 둔다.
3. 현재 작업과 관련된 파일만 stage한다.
4. 남아 있으면 최종 보고에 언급한다.
