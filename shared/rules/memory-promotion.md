# 메모리 승격 정책

## 메모리 상태

`session-memory.md`는 개별 세션의 원시 관찰을 담는다.

`agent-rules-candidates.md`는 durable rule이 될 가능성이 있는 반복 패턴이나
높은 확신의 패턴을 담는다.

대상 저장소 문서는 안정적이고 팀이 봐도 되는 규칙만 담는다.

## 승격 체크리스트

메모리 항목을 대상 프로젝트 문서나 `shared/`로 승격하기 전에 확인한다.

- 한 번 이상 반복되었거나 영향이 크다.
- 다른 에이전트가 실행할 수 있다.
- 비밀값이나 로컬 도구 상태를 노출하지 않는다.
- 임시 workaround를 영구 규칙처럼 기록하지 않는다.
- 대상 저장소의 기존 안전 또는 검증 모델을 강화한다.

## 승격 금지

다음은 승격하지 않는다.

- 1회성 선호
- 한 세션에만 해당하는 전술 메모
- 한 프로젝트의 임시 전략이나 관계 맥락
- 타인의 행동에 대한 코멘트
- 대상 저장소 협업자를 혼란스럽게 만들 내용

## 메모리 위치

프로젝트별 히스토리와 학습은 각 프로젝트 안의 명시된 에이전트 메모리 문서에
누적한다. 예: `docs/agent-memory.md`.

특정 도구가 만든 `.omc/project-memory.json` 같은 상태 파일은 지속 메모리 원본으로
쓰지 않는다. 발견하면 유효한 내용을 프로젝트 메모리 문서로 요약 이관하고, 도구
종속 상태에 계속 누적하지 않는다.

`ai-control-tower`의 `projects/`는 프로젝트별 팀 맥락을, `shared/`는 여러
프로젝트에 반복 적용할 수 있는 규칙, 템플릿, 스킬을 저장하는 곳이다.
