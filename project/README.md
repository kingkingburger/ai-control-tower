# 프로젝트 문서

`project/`는 `ai-control-tower` 자체를 운영하기 위한 프로젝트 문서를 둔다.
단일 파일을 루트에 쌓지 않고 문서 성격별 하위 폴더에 넣는다.

## 폴더

- `roadmaps/`: 단계별 목표, 주차별 실행 계획, 최종 상태 정의.
- `inventories/`: 스킬, 훅, 메모리, 배포 대상 같은 자산 목록.
- `distribution-sync/`: 원본/배포본 동기화 정책, dry-run 결과, drift 처리 계획.
- `runbooks/`: 반복 운영 절차와 장애/복구 체크리스트.
