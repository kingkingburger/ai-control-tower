01
PARADIGM SHIFT

프롬프트 잘 치는
시대는 끝났다

환경이 잘 세팅되면, 프롬프트 하나하나의 질보다 환경 품질이 AI 레버리지를 결정한다

SHIFT

프롬프트 질 < 환경 세팅

📝

예전: Prompt Engineering

  • 프롬프트를 정말 잘 깎아서 넣어야 한다
  • 한 번의 질문에 최적의 답을 뽑아내는 기술
  • "프롬프트 엔지니어"라는 직분도 존재
  • 결과: 일회성 결과물
⚙

지금: Environment Engineering

  • CLAUDE.md, MCP, 스킬이 잘 세팅된 환경
  • 빠르게 요구사항을 쏟아내는 것이 더 중요
  • 오타가 나도 괜찮다
  • 결과: 시스템이 복리로 성장

"Claude Code 같은 툴이 나오면서, 환경이 잘 세팅되면 프롬프트 하나하나의 질보다는 어떤 환경을 세팅했냐에 따라서 AI를 레버리지할 수 있는 업사이드가 굉장히 달라지는 거 같아요."

— 장원준

CLOSING INSIGHT

1년씩 앞서가는 사람은
논리적으로 없다

꽤 큰 자신감으로 스텝 밟아도 되는 시기

INSIGHT

지금은 자신감을 가질 시기

🌍

미국(영어권)의 강점

  • 절대 정보량이 많다
  • 트위터의 디베이트 문화
  • 파운데이션 모델 밸류체인
🇰🇷

한국(서울)의 강점

  • 빠른 실행력
  • 하네스(Harness) 레벨의 엣지
  • AI를 업무에 도입하는 관점에서 앞서는 부분
💡

AI를 잘 쓰는 사람의 패턴

  • 특정 세대나 직군으로 한정되지 않음
  • 원래 일을 잘하던 사람들이 AI도 잘 쓴다
  • 핵심 자질: 언러닝(Unlearning)을 잘하는 사람
⏱

지금이 기회

  • 같은 타이밍에 기어지고 있다
  • 하루 이틀 빠른 사람은 있을 수 있지만
  • 1년씩 앞서가는 사람은 없다

Takeaways

  • 01 프롬프트 잘 치는 시대는 끝났다.
    환경(CLAUDE.md, MCP, 스킬)의 품질이 AI 레버리지를 결정한다.
  • 02 만든 건 초안이다.
    Build → Use → Notice → Debug → Fix → Document 사이클을 반복하며 복리를 쌓아라.
  • 03 엔진보다 하네스가 중요하다.
    모델 자체보다, 모델을 어떻게 엮어놓느냐가 성능을 결정한다.
  • 04 AI 관리자로 역할을 전환하라.
    계획 → 위임 → 리뷰 → 피드백(Compound). 이것이 새로운 핵심 루프다.
