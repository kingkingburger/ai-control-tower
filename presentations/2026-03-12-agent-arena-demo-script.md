## 발표 전 체크리스트

- [ ] M&S 주제로 Arena 사전 실행하여 결과 저장 (백업용)
- [ ] HTML 슬라이드 파일 브라우저에서 열기 (F11 전체화면)

- [ ] 키보드 방향키로 슬라이드 넘기기 확인

### Arena 사전 실행 명령어 (전날 또는 당일 아침)

```
/agent-arena "제안 완료 4개 고객 중 후속 영업 리소스 우선 집중 대상을 결정해야 합니다.

옵션:
A. GS오토모티브
B. 삼성SDS 물류
C. 피로세
D. 삼성디스플레이

배경: 4개 고객 모두 제안 자료 전달 완료 후 피드백 대기 중. 한정된 영업 인력(2~3명)으로 어디를 먼저 집중 공략할지 결정 필요. 고객별로 규모, 긴급도, 기존 관계, 기술 적합도가 모두 다름."
```

## Q&A 예상 질문 및 답변

### Q1: "결과를 얼마나 신뢰할 수 있나요?"

> "100% 정답을 준다고 보진 않습니다. 하지만 혼자 생각하면 놓칠 수 있는 관점을 구조적으로 보여줍니다. 최종 결정은 사람이 하되, 판단의 재료를 풍성하게 만들어주는 도구라고 보시면 됩니다."

### Q2: "한 번 돌리는 데 얼마나 걸리나요?"

> "3인 프리셋은 2~3분, 8인 프리셋은 5~8분 정도입니다. 짧은 점심시간에도 충분히 돌릴 수 있습니다."

### Q3: "우리 팀 주제를 넣으려면 어떻게 하면 되나요?"

> "Claude Code에서 `/agent-arena '주제'` 한 줄이면 됩니다. 주제를 구체적으로 쓸수록 결과가 좋습니다. 옵션을 명시하고, 배경 상황을 넣어주면 더 깊은 분석이 나옵니다."

### Q4: "기밀 정보를 넣어도 되나요?"

> "Claude Code는 로컬에서 실행되고, 입력 데이터가 모델 학습에 사용되지 않습니다. 다만 사내 보안 정책에 따라 민감 정보는 별도로 확인해주시면 좋겠습니다."

### Q5: "짜장면 vs 짬뽕 같은 가벼운 주제도 되나요?"

> "네, 실제로 돌려봤습니다. (웃음) 3월이라 계절 변수, 영양 균형, 배달 vs 매장 등 생각지 못한 관점이 나왔습니다. 가벼운 주제로 먼저 체험해보시는 것도 좋은 방법입니다."
