# 시뮬레이션 엔진 플랫폼 — 요구사항 정의

> 작성일: 2026-03-11
> 상태: 초기 요구사항 정의 완료, 베이스 플랫폼 미선택

## 원본 요구사항

"Isaac Sim 같은 우리만의 플랫폼 엔진을 만들고 싶다"

## 목표

스마트팩토리/물류 고객을 위한 **공정 시뮬레이션 + 최적화 플랫폼** 제품 개발

## 범위와 단계

| 단계 | 기능 | 설명 |
|-------|------|------|
| **MVP** | 공정 시뮬레이션 + 최적화 | 공장 라인 3D 모델링 → 병목 분석 → 배치 최적화 |
| 2단계 | 실시간 디지털 트윈 모니터링 | IoT 센서 데이터 연동 → 3D 가상 공장에 실시간 반영 → 이상 감지 |
| 3단계 | 가상 커미셔닝 | PLC 로직 가상 테스트 + 설비 검증 (실제 구축 전) |
| 4단계 | AI 학습용 가상 환경 | 강화학습/ML 모델 학습을 위한 시뮬레이션 환경 제공 |

## 결정

| 항목 | 결정 | 비고 |
|------|------|------|
| 도메인 | 디지털 트윈 + 제조/공정 시뮬레이션 | |
| 구축 전략 | 기존 엔진 위에 확장 | Isaac Sim 방식 |
| 사용자 | 외부 고객 제품 (B2B SaaS/솔루션) | |
| MVP 우선순위 | 공정 시뮬레이션 + 최적화 | |
| 타겟 산업 | 스마트팩토리/제조업, 물류/유통 | |
| 베이스 플랫폼 | **미정** | Omniverse vs Unity vs Unreal 비교 필요 |
| 기술 스택 | **미정** | 베이스 플랫폼 선택에 따라 결정 |

## 팀

- 규모: 3-4명
- 기존 전문 역량: 특정 분야 강점 없음 (빌딩 필요)
- 기술 스택: 미정

## 리스크

1. **역량 갭**: 3D 그래픽스, 물리 엔진, 제조 도메인 지식 모두 부재 → 학습 또는 채용 필요
2. **베이스 플랫폼 의존성**: 플랫폼 선택이 기술 스택, 채용 방향, 개발 속도를 전부 결정
3. **스코프 과다**: 4개 Phase 전체는 3-4명으로 수년 소요 → MVP에 집중 필수
4. **경쟁**: Siemens(Tecnomatix), Dassault(DELMIA), PTC(Vuforia) 등 대형 업체 존재

## 아키텍처 참고: Isaac Sim 레이어 구조

```
┌─────────────────────────────────────────────┐
│           Application Layer                  │  ← 우리가 만들 영역
│  공정 시뮬레이션 · 최적화 · 모니터링          │
├─────────────────────────────────────────────┤
│           Extensions / Plugins               │  ← 도메인 특화 확장
│  공장 모델 임포터 · IoT 브릿지 · 분석 엔진    │
├─────────────────────────────────────────────┤
│           App Framework                      │  ← 베이스 플랫폼 제공
│  UI · 스크립팅 · 확장 시스템                   │
├─────────────────────────────────────────────┤
│           Platform                           │
│  씬 포맷(USD/glTF) · 협업 · 외부 도구 연동    │
├─────────────────────────────────────────────┤
│           Engine                             │
│  물리 엔진 · 렌더러 · GPU 가속                │
└─────────────────────────────────────────────┘
```
