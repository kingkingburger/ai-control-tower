# 기본 프로젝트 프로필

전용 private overlay가 아직 없는 저장소에 이 프로필을 사용한다.

## 시작 절차

1. 대상 저장소 지침을 읽는다.
2. 스택과 명령어를 감지한다.
3. 개인 메모를 대상 저장소에 쓰지 않는다.
4. 다시 방문할 가능성이 높은 프로젝트면 `harness/projects/<project>/` 아래에
   전용 overlay를 만든다.

## 기본값

- 개인 메모리는 이 control tower에 둔다.
- 공유 저장소 지침은 간결하고 협업자에게 안전하게 유지한다.
- 위험이 크지 않으면 넓고 느린 검사보다 집중 검증을 선호한다.
