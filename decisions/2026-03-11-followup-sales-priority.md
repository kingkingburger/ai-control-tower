# Arena 토론 결과: 후속 영업 우선순위

**일시**: 2026-03-11
**프리셋**: 8인 (비전가, 옹호자, 비판자, 유저대변인, 기술설계자, 품질악마, 현실주의자 + 종합자)
**라운드**: 3회

---

## 추천안

**옵션 B: 피로세 선행 + GS오토모티브 병렬 탐색 → 삼성SDS Q3 조건부**

3라운드 토론을 거치며 7명 중 6명이 수렴한 결론이다. 피로세는 의사결정 속도, Pain Point 명확성, 현금흐름 확보 측면에서 가장 즉시 실행 가능한 고객이다. GS오토모티브는 자동차 도메인 진입 기회 자체가 드물어 탐색 병행이 유효하다. 삼성SDS는 현금흐름이 버텨주는 Q3 이후, 피로세 레퍼런스 확보 조건 하에서만 본격 투자한다. 삼성디스플레이는 의사결정 복잡도가 가장 높아 현 시점 후순위로 확정한다.

---

## 옵션 비교

### 옵션 A: 삼성SDS 물류 단독 우선
- **핵심**: 삼성 생태계 진입 + 물류 AI 메가트렌드로 레버리지 극대화
- **장점**: "삼성SDS 납품사" 타이틀의 레퍼런스 승수 효과 / 물류 AI 패턴 표준화로 솔루션 재활용성 최고 / 삼성디스플레이 등 계열사 연쇄 확장 가능
- **리스크**: 벤더 선정까지 수십 단계 + 영업 사이클 1.5~2년으로 현금흐름 위기 / 첼로(Cello) 자체 플랫폼과 기능 충돌 및 내재화 로드맵 공식화 / NDA로 레퍼런스 비공개 → 영업 자산화 불가
- **적합 조건**: 전담 엔터프라이즈 영업 인력 확보 완료 + 6개월 이상 런웨이 확보 + 피로세/GS오토 계약 클로즈 이후

### 옵션 B: 피로세 선행 + GS오토 병렬 + 삼성SDS Q3 조건부 ✅ 추천
- **핵심**: 빠른 클로징으로 현금 확보 후 엔터프라이즈 순차 확장
- **장점**: 피로세는 내부 결재 라인 짧고 Pain Point 명확 → 클로징 속도 최고 / GS오토는 원가 압박으로 AI 도입 저항 낮고 자동차 도메인 진입 기회 희소 / Q2 PoC 완료 시 Q3~Q4 삼성SDS 진입에 레퍼런스 탄약 확보
- **리스크**: 피로세 No-Go 시 전체 타임라인 밀림(선형 종속) / 소형 레퍼런스가 엔터프라이즈 문을 여는지 검증 필요
- **적합 조건**: 현재 런웨이 6개월 미만 또는 엔터프라이즈 전담 조직 미확보 상태 (= 현재 상황)

### 옵션 C: 피로세 단독 집중
- **핵심**: 리소스 집중으로 첫 클로징 확실하게 확보
- **장점**: 실행 집중도 최고 / 리소스 분산 없음
- **리스크**: GS오토 선점 기회 상실 / 피로세 No-Go 시 대안 없음
- **적합 조건**: 팀 인원이 1~2명으로 병렬 실행 자체가 불가한 경우

### 옵션 D: 삼성디스플레이 우선
- **핵심**: 대형 디스플레이 제조 AI 레퍼런스 확보
- **장점**: 대형 제조업 레퍼런스 가치 / 삼성 계열사 연결 가능성
- **리스크**: 의사결정권자 도달 시간 가장 길고 복잡도 최고 / 커스터마이징 블랙홀 리스크 / 이행 실패 시 평판 손상 극단적
- **적합 조건**: 대형 제조업 특화 솔루션 이미 완성 + 내부 챔피언 확보된 상태

## 합의 사항

3라운드를 거쳐 전원(또는 대다수)이 동의한 포인트:

1. **피로세 최우선 착수** — 7명 중 6명 최종 수렴 (비전가 포함 Phase 2에서 입장 전환)
2. **공개 레퍼런스 조항 계약 필수** — 피로세 계약 협상 시 레퍼런스 공개 허용 조항 반드시 포함
3. **삼성SDS는 Q3 이후 조건부** — 즉시 1순위 불가. 피로세 클로징 + 전담 인력 확보 후 진입
4. **삼성디스플레이 최후순위** — 의사결정 복잡도와 커스터마이징 리스크로 현 단계 집중 투자 불가
5. **피로세 실사 Go/No-Go 기준 사전 명문화** — 예산 확보 확인 / 의사결정권자 직접 접촉 / 6개월 내 도입 의지 (3개 중 2개 이상 충족)
6. **플랜B 필수** — 피로세 No-Go 시 GS오토모티브 즉시 1순위 전환

### Phase 2: 주요 반박 포인트

- **라운드 1**: 현실주의자의 "삼성SDS 영업 사이클 1.5~2년 — 현금 흐름 못 버팀" 지적이 핵심 반전점. 비판자가 "첼로 API 협의·보안심사는 표준화가 줄여주는 영역 아님"으로 기술설계자 근거 무력화. 유저대변인이 "레퍼런스가 문을 연다는 것은 공급자 관점 착각"으로 옹호자 논리 반박.
- **라운드 2**: 대규모 수렴 발생. 비전가·옹호자·기술설계자 3명 모두 입장 전환. 유저대변인이 GS오토 재평가(의사결정 레이어 얇음, AI 도입 저항 낮음). 품질악마와 비판자는 "병렬 = 양쪽 다 절반만" 경고로 수렴 속에서도 실행 규율 유지 촉구.
- **라운드 3**: 세부 실행 조건 합의 수렴. 피로세 실사 기간(비판자 4주 vs 현실주의자 3주), Go 기준 3개 항목 명문화, GS오토 자동차 인증 지연(6개월+) 함정 추가 경고(품질악마), 삼성SDS Q4 진입 시 경쟁사 레퍼런스 격차 탈락 가능성 제기(품질악마).

## 다음 단계

1. **[즉시 — 3월 3~4주] 피로세 실사 착수**: Go/No-Go 기준 3개 항목(예산 확보 확인 / 의사결정권자 직접 접촉 / 6개월 내 도입 의지) 사전 명문화 후 4주 실사 진행. 계약 협상 시 공개 레퍼런스 허용 조항 필수 포함.

2. **[2주 내 병행] GS오토모티브 초기 접촉 개시**: 피로세 실사와 동시에 GS오토 탐색 병행. 단, 자동차 산업 인증 지연(6개월+) 리스크 사전 확인. 피로세 No-Go 시 즉시 GS오토 1순위 전환 플랜B 준비.

3. **[Q2] 피로세/GS오토 PoC 완료 → Q3 삼성SDS 진입 검토**: 피로세 레퍼런스 확보 + 전담 엔터프라이즈 영업 인력 확보 조건 충족 시 삼성SDS 파일럿 협의 개시. 기술설계자 권고대로 첼로 레이어 분리 아키텍처 사전 검증 완료 후 진입. 삼성디스플레이는 위 조건 모두 완료 후 별도 판단.
