# Arena 스킬 시연용 - 전사 조직별 베스트 주제

> Claude Code 입문자 대상 Arena 스킬 실용성 시연을 위한 주제 목록
> 선정 기준: 2026년 3월 1~2주차 Notion/Slack/Google Calendar에서 확인된 **현재 진행형 이슈**

---

## 1. 경영지원팀

**"TeamViewer 라이선스 오딧 대응: 갱신 vs 대체 솔루션 vs 사용 축소"**

- 근거: 주간회의(3/9)에서 **시급** 이슈로 강조됨. 오딧 메일 수신, 정확한 사용 현황 파악 필요
- Arena 적합성: 비용(라이선스 갱신비) vs 보안(원격접속 통제) vs 업무 연속성(현장 출장팀 의존도) 3축 트레이드오프. 정답이 없는 전형적 의사결정

## 2. 디자인팀 (UI/UX)

**"삼성중공업 좌측 네비게이션 열림 시 화면 구성: 오버레이 vs 콘텐츠 축소 vs 미니 아이콘 모드"**

- 근거: 삼성중공업 디자인 리뷰(3/10) 진행 중. "좌측 네비게이션 열렸을 때 화면 디자인 추가" 요청 건
- Arena 적합성: 3D 모니터링 화면 특성상 콘텐츠 영역 축소가 치명적일 수 있음. UX/개발 난이도/고객 선호 모두 고려 필요

## 3. 기획팀

**"잉글우드랩 데이터 구조: 설비 종속(설비→측정값/셋팅값) vs 카테고리 종속(측정값→설비별 N개)"**

- 근거: 잉글우드랩 주간회의(3/9)에서 "측정값·셋팅값·AI예측값 하위에 설비운영정보가 종속되는 것인지?" 혼선 발생
- Arena 적합성: 도메인 모델 방향이 이후 개발 전체를 좌우함. 기획/개발/현장 관점이 모두 다를 수 있는 구조적 의사결정

## 4. XR센터 (유니티/3D팀)

**"유니티 시뮬레이션 매번 새 로딩 vs 인앱 목록 조회·불러오기 기능 도입"**

- 근거: Notion에 직접 등록된 제안 - "시뮬레이션마다 유니티 새로 로딩하는 시간을 줄일 수 있을 것 같음"
- Arena 적합성: 개발 공수(신기능) vs 사용자 경험(로딩 시간) vs 메모리 안정성(씬 전환 이슈) 트레이드오프. 현장 운영 관점도 중요

## 5. DT센터 (개발팀)

**"HUB 대시보드를 노코딩에서 LLM 기반 생성으로 전환할 것인가"**

- 근거: 실제 고민 문서(3/9)가 존재하며 Phase 1~3 제안서까지 작성된 상태
- Arena 적합성: 기술 리스크(LLM hallucination) vs ROI(커스텀 대시보드 자동 생성) vs 타이밍(제품 로드맵과의 충돌). 가장 임팩트가 큰 기술 의사결정

## 6. M&S팀 (영업/마케팅)

**"제안 완료 4개 고객 중 후속 영업 리소스 우선 집중 대상: GS오토모티브 vs 삼성SDS 물류 vs 피로세 vs 삼성디스플레이"**

- 근거: 주간회의(3/9) - 제안 자료 전달 완료 후 전부 피드백 대기 중
- Arena 적합성: 고객별 규모/긴급도/기존관계/기술적합도가 모두 다름. 한정된 영업 인력으로 어디를 먼저 공략할지

## 7. Physical AI/시뮬레이터팀

**"AMR 협업 기능 타겟: 인천공항 물류부 vs 현대위아 - 3가지 시나리오 중 집중 방향"**

- 근거: 주간회의(3/9) - 기술 서베이 진행 예정, "타겟 조속히 설정하여 다음 미팅 시 보고" 요청
- Arena 적합성: 시장성/기술 난이도/레퍼런스 가치가 상이한 두 고객. 초기 타겟이 팀 방향성 전체를 결정

## 8. 전사 공통 (AI 네이티브 전환)

**"비개발 조직(M&S·경영본부)의 AI 도구 선정: Claude Code 계정 공유 vs Cursor vs ChatGPT Plus vs 도메인 특화 도구"**

- 근거: AI 도구 단위 리더(3/3) - "M&S 및 경영본부는 내부 논의 후 도구 결정"으로 아직 **보류 상태**
- Arena 적합성: 개발 조직은 Claude Code로 가닥이 잡혔지만 비개발 조직은 업무 성격이 달라 적합 도구가 다름. 비용/학습곡선/실제 활용도 모두 변수

| **입문자 공감** | 각 팀이 "이건 우리 이야기인데?" 하고 느낄 수 있는 주제 |
