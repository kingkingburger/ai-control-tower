# 문제 찾기

목표를 바로 고르기 전에, 반복되는 불편을 실행 가능한 문제로 바꾸는 기록 공간이다.

## 운영 원칙

- 기록 위치는 `problem-finding/`으로 독립시킨다.
- 문제 발견 기록은 매주 하나씩 작성한다.
- 각 기록은 반드시 `15분 해결책`과 `그래도 남는 것`을 구분한다.
- 한 달에 한 번, 4개의 기록 중 하나를 실제 산출물로 발전시킨다.

## 평가 기준

각 후보는 0-3점으로 평가한다.

- 반복성: 자주 다시 나타나는가?
- 고통: 안 고치면 계속 손해인가?
- 증거: 고쳤는지 확인 가능한가?
- 확장성: 이걸 고치면 다른 문제도 같이 나아지는가?

## 매일 할 일

매일 해야 할 일은 문제를 해결하는 것이 아니다.

1. 오늘 불편했던 것 5개를 적는다.
2. 바로 해결할 수 있는 `15분 해결책`을 적는다.
3. 그 해결책을 해도 `그래도 남는 것`을 한 줄로 적는다.
4. 이번 주 후보에 올릴지 말지만 판단한다.

커밋은 선택 사항이다. 중요한 것은 오늘 작업이 어떤 장기 문제에 연결되는지 한 줄로
설명할 수 있는가이다.
