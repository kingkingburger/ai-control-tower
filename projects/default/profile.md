# 기본 프로젝트 프로필

전용 프로젝트 프로필이 아직 없는 저장소에 이 프로필을 사용한다.

## 시작 절차

1. 대상 저장소 지침을 읽는다.
2. 스택과 명령어를 감지한다.
3. `shared/rules/work-style.md`의 언어 비종속 작업 스타일을 적용한다.
4. 로컬 운영 메모를 대상 저장소에 쓰지 않는다.
5. 다시 방문할 가능성이 높은 프로젝트면 `projects/<project>/` 아래에
   전용 프로필을 만든다.

## 기본값

- 프로젝트별 운영 메모리는 이 control tower의 `projects/<project>/`에 둔다.
- 대상 저장소 지침은 간결하고 협업자에게 안전하게 유지한다.
- 위험이 크지 않으면 넓고 느린 검사보다 집중 검증을 선호한다.
- 작업 방식은 `shared/rules/work-style.md`를 기본값으로 삼되, 대상 저장소의 더
  구체적인 안전/검증/커밋 규칙을 우선한다.
