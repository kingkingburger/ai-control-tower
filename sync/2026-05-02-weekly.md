## 상세 내역

### 1. octoto 1.0.22 패치 (4/30 배포)

**패치노트**

- UI/UX 수정 (다수)

### 2. knox 로그인/로깅 연동 (4/28~29)

- **로그인 분기**: knox 미로그인 → 안내 / 로그인됨 + 슈퍼유저 → 자동 진입 / 로그인됨 + 권한없음 → 차단 안내
- **보조 경로**: 특정 URL 접근 시 기존 id/pw 로그인 (sdi hub의 admin-login 방식 차용)
- **레퍼런스 코드**: `D:\reference2\octopus\apps\web\hub`
- **로깅 개선**: `serviceName`을 body로 받아 로깅 (기존엔 service만 받았음)
- **의미 변화**: knox 연동 후 `user_service_access` 의미가 달라짐 — 영향 범위 점검

### 3. 삼성 부서 API & roleGroup 동기화 (4/27)

- **API**: `getEmpDept.do?gb=D` (URL 가변, env 처리)
- **응답**: `{DEPTCD, DEPTNM}` 1500여 건
- **구현**:
  - 일 1회 자동 + 수동 동기화 버튼
  - 모달에서 JSON/CSV/URL 3가지 입력 방식
  - 검색·페이징 처리
  - 권한그룹 탭 → 부서 버튼 신설, 부서 권한그룹은 별도 표시
- **env 추가**: `.env`, `.env.docker` 양쪽 동기화 (메모리화)

### 4. 중공업(SHI) 분기 처리 (4/28~29)

- **인트로 화면**: 진주하님 협조로 octopus hub의 중공업 인트로 적용 (`COMPANY=shi` 환경변수 분기)
- **사이드바**: 중공업 환경에선 "권한신청" 메뉴 비표시
- **권한 동기화**: knox 로그인 시 부서 자동 매칭, 신규 부서 생성은 차단(codes측 합의)

### 5. 사용자-권한그룹 편집 UX 개선 (4/29)

- 진입 속도 개선 (느림 이슈 해결)
- 사용자에 할당된 권한그룹만 표시 (전체가 아닌)
- 신규 권한그룹 생성 가능, 생성 시 그리드 좌측 최신순 정렬
- 사용권한 / 관리권한 분리 방향성 확정
- "직접입력" 제거, "활성 처리" 토글 제거
- 서비스 권한그룹 상세 모달 메뉴권한 403 수정
- 서비스 진입 시 등록된 부서만 표시 (전체 부서 X)
- 슈퍼유저 처리 재조정
